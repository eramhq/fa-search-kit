# fa-search-kit demo (built site)

The live demo of [fa-search-kit](https://github.com/eramhq/fa-search-kit): stock Pagefind and
Pagefind with fa-search-kit side by side, over 300 Persian Wikipedia articles and 300 Digikala
product titles. This branch holds only the built site, from `node demo/build.ts` (one build serves any path: the page sets Pagefind's `baseUrl` from its own address).

# هماهنگی نمایه‌سازی و جستجو

برای سندها و عبارت‌های جستجو یک پیکربندی تحلیلگر به کار ببرید. تفاوت حالت‌ها عمدی است: حالت نمایه می‌تواند شکل‌های جایگزین اضافه کند، ولی حالت جستجو عبارت اصلی هر توکن را نگه می‌دارد.

```js
import { createAnalyzer } from "fa-search-kit";
const analyzer = createAnalyzer();
console.log(JSON.stringify(analyzer.analyze("کتاب‌خانه", { mode: "index" }))); // => ["کتابخانه","کتاب","خانه"]
console.log(JSON.stringify(analyzer.analyze("کتاب‌خانه", { mode: "query" }))); // => ["کتابخانه"]
console.log(JSON.stringify(analyzer.analyze("آسمان", { mode: "index" }))); // => ["آسمان","اسمان"]
console.log(JSON.stringify(analyzer.analyze("آسمان", { mode: "query" }))); // => ["آسمان"]
```

## چرا دو حالت متفاوت‌اند؟

حالت پیش‌فرض `analyze(text)` نمایه است. با گزینه‌های پیش‌فرض می‌تواند بخش‌های ترکیب، شکل دیگر نیم‌فاصله و شکل بدون کلاه آ را اضافه کند. حالت جستجو مانع از آن می‌شود که همه این جایگزین‌ها هم‌زمان لازم شوند. برای متن و تنظیمات یکسان، عبارت‌های جستجو زیرمجموعه عبارت‌های نمایه هستند. این ویژگی تضمین نمی‌کند که هر دو متن متفاوت دلخواه با هم تطبیق داشته باشند.

تحلیلگر عبارت‌های تکراری را حذف نمی‌کند. رابط‌ها عبارت‌های تکراری جستجو را حذف می‌کنند تا یک عبارت چند بار شمرده نشود. تکرار در نمایه می‌تواند بر رتبه‌بندی موتور اثر بگذارد. حذف واژه‌های توقف در سطح تحلیلگر وجود ندارد.

## تنظیمات را صریح مشترک کنید

برای موتور درون حافظه، یک تحلیلگر بسازید و `{ analyzer }` را به رابط و اصلاح جستجو بدهید. در این حالت سایر گزینه‌های تحلیلگر روی رابط نادیده گرفته می‌شوند. وقتی ساخت سایت ایستا و بسته مرورگر جدا هستند، پروفایل، نسخه واژه‌نامه، حالت فعل و گزینه‌ها را در تنظیمات مشترک یا آرگومان‌های معادل نگه دارید. شیء تحلیلگر را به JSON تبدیل نکنید؛ آن را از تنظیمات نسخه‌دار دوباره بسازید.

اگر تحلیلگر full را به MiniSearch با OR می‌دهید و پیش‌فرض معمول رابط را می‌خواهید، `verbs: "stem"` را صریح تعیین کنید. رابط تنظیمات تحلیلگر آماده را تغییر نمی‌دهد.

## ساخت و استقرار هماهنگ

پس از تغییر پروفایل، یکسان‌سازی، اتصال بخش‌ها، گزینه‌های بن‌یابی یا ضمیر پیوسته، حالت فعل، داده واژه‌نامه یا نسخه‌ای از بسته که عبارت‌ها را عوض می‌کند، نمایه را دوباره بسازید. تغییراتی مانند `exactTerms` در Orama یا `terms`، `surface` و پردازش عنوان در Pagefind نیز داده نمایه را تغییر می‌دهند. با تغییر محتوا، واژه‌های اصلاح جستجو را هم دوباره بسازید.

نمایه، بسته جستجوی مرورگر و واژه‌های اختیاری را به صورت نسخه‌های سازگار منتشر کنید. نمایه ذخیره‌شده همچنان به روش بارگذاری مخصوص موتور و همان رابط در سمت جستجو نیاز دارد. این کتابخانه قالب عمومی ذخیره نمایه یا ابزار مهاجرت ندارد.

متن اصلی را مرجع نمایش و ساخت دوباره نگه دارید. اگر فقط بن‌ها را ذخیره کنید، بازیابی متن یا موقعیت درست در متن اصلی ممکن نیست.

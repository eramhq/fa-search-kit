# پردازش متن فارسی برای جستجو

fa-search-kit متن فارسی را برای جستجوی واژه‌ای آماده می‌کند: شکل‌های متفاوت نوشتن را یکسان می‌کند، متن را به توکن می‌شکند و در صورت نیاز، بن واژه یا صورت پایه آن را با کمک واژه‌نامه به دست می‌آورد. رابط‌های آماده آن به Pagefind، Orama، MiniSearch، FlexSearch و Lunr وصل می‌شوند.

پس از [نصب از سورس](installation.md)، عبارت جستجو را پردازش کنید:

```js
import { createAnalyzer } from "fa-search-kit";
const analyzer = createAnalyzer();
console.log(JSON.stringify(analyzer.analyze("كتابهاي من", { mode: "query" }))); // => ["کتاب","من"]
```

رشته‌های خروجی عبارت‌های مورد استفاده در جستجو هستند، نه متن مناسب نمایش. رشته اصلی تغییر نمی‌کند. ساخت نمایه، رتبه‌بندی و بازیابی سندها همچنان کار موتور جستجو است. این کتابخانه جستجوی معنایی یا سرویس هوش مصنوعی نیست؛ پردازش هنگام اجرا بر پایه قواعد و داده‌های همراه بسته انجام می‌شود.

## کاربرد و محدودیت

برای جستجو در مستندات، مقاله‌ها و کالاهای فارسی مناسب است؛ به‌ویژه وقتی تفاوت حروف عربی، نوع رقم یا نیم‌فاصله نباید مانع یافتن محتوا شود. متن خوانا را در کنار عبارت‌های نمایه نگه دارید و تنظیمات یکسانی برای نمایه‌سازی و جستجو به کار ببرید.

کتابخانه پایگاه جستجو، سیاست رتبه‌بندی، ترجمه، مترادف‌های عمومی، تبدیل فینگلیش، درک بافت جمله یا دستور زبان کامل فارسی فراهم نمی‌کند. قواعد ممکن است واژه‌های نامرتبط را یکی کنند یا صورت درستی را تشخیص ندهند. بخش لاتین متن نیز به توکن تبدیل می‌شود و حروف رایج آن کوچک می‌شوند، اما تحلیلگر بن‌یاب انگلیسی یا فهرست واژه‌های توقف ندارد.

## جستجوی مستندات ارم

وب‌سایت ارم برای مستندات فارسی از Pagefind با `profile: "full"`، واژه‌نامه همراه بسته و `verbs: "lemma"` استفاده می‌کند. مسیر جایگزین محلی نیز همین تحلیلگر را دارد. اصلاح اختیاری جستجو در صفحه محصول نمایش داده می‌شود؛ این قابلیت در جستجوی مستندات فعال نیست.

پیش از استفاده عملی، [داده‌ها و محدودیت‌ها](data-and-benchmarks.md) و [اشکال‌های شناخته‌شده](recipes.md) را بخوانید.

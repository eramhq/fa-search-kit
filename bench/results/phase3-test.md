# fa-search-kit benchmark: phase3-test

Generated by `node bench/report.ts --name phase3-test --split test` on 2026-09-28. Method: [bench/README.md](../README.md).
Split: **test** (the test half of the targets, bench/lib/split.ts).

Recall@10 in %: the share of queries whose target document is in the top 10. Each corpus has 20,000 documents;
*n* is the number of queries of that type. Rows with fewer than 30 queries are left out.
Configs: **stock** = engine defaults; **tuned** = the engine's closest language option + typo tolerance;
**snowball** = Snowball 3.1.1 Persian stemmer plugged in naively; **fa-light / fa-standard / fa-full** = fa-search-kit's profiles through its shipped adapters; **p1-*** = the same profiles through Phase 1's bench wiring.
Verb rows also get a per-lemma macro average (last section), since a few verbs (شد, می‌شود) dominate them.
